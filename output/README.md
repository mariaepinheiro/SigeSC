# Output Directory

This directory holds the pipeline-generated datasets. The data files are too large for the Git repository and are distributed via [GitHub Release (`v1.0`)](../../releases/tag/v1.0).

## Setup

Download the zip files from the release and extract them into the corresponding subdirectories:

```
output/
├── stage2_attributes/
│   └── correspondencia_setores.csv          (176 KB)
├── stage3_population/
│   ├── dataset_familias_2025.csv            (10 MB)
│   └── dataset_pessoas_com_Ordem_final.csv  (48 MB)
├── stage4_update_2025/
│   └── residencias_2025.csv                 (45 MB)
└── results/                                 ← generated by 10_allocation_model.jl
```

## Directory descriptions

| Directory | Contents |
|-----------|----------|
| `stage1_residences/` | Processed CNEFE residence registry (intermediate) |
| `stage2_attributes/` | Census tract correspondence and imputed residence attributes |
| `stage3_population/` | Synthesized families and individuals (family composition output) |
| `stage4_update_2025/` | Residence registry updated to 2025 |
| `results/` | Allocation output — generated by running `src/10_allocation_model.jl` |

## Note

Do **not** commit the CSV files to the repository. They are listed in `.gitignore`.
